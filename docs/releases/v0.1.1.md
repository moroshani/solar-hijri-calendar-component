# v0.1.1 - Foundation Release

Publication status: locally verified release candidate; tag and npm publication pending

Version `0.1.1` establishes the existing Solar Hijri Calendar Component
foundation on npm. It deliberately does not expand the public component API.

## Highlights

- Controlled React calendars for single, range, and multiple-date selection.
- Framework-neutral date math, constraints, and selection entry points.
- Persian and English labels with RTL-aware presentation.
- Explicit month and year controls in the responsive public testing lab.
- ESM, CommonJS, TypeScript declaration, React, core, and CSS package exports.
- Updated dependencies with a zero-high-severity-vulnerability release target.

## Since v0.1.0

- Rebuilt the testing lab around practical desktop and mobile evaluation.
- Expanded the Playwright interaction matrix from 15 to 25 checks.
- Added controlled month/year navigation coverage.
- Reconciled package architecture, roadmap, release boundaries, and durable
  maintainer handoff documentation.
- Updated the dependency graph and security overrides.
